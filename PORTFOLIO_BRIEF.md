## Visual Direction

## Images

Place images in `public/images/` using descriptive lowercase, hyphenated names:

```text
public/images/profile-photo.jpg
public/images/goloca-logo.png
public/images/project-dashboard.webp
```

Use an image in React like this:

```jsx
<img src="/images/profile-photo.jpg" alt="Chantha Sinat" />
```

Prefer WebP or JPG for photographs and PNG/SVG for logos. Compress large files before adding them. Never delete or overwrite user-supplied images unless explicitly asked.

## Development Commands

```bash
npm install       # Install dependencies after a fresh clone
npm run dev       # Start the local Vite preview
npm run lint      # Check JavaScript and React code
npm run build     # Create the production build in dist/
```

Before handoff or deployment, run both `npm run lint` and `npm run build`.

## Git and Deployment

- Repository: `https://github.com/ChanthaSinat/portfolio.git`
- Main branch: `main`
- Remote name: `github`
- Hosting target: Vercel, using the Vite preset.
- Vercel build command: `npm run build`
- Vercel output directory: `dist`
- No environment variables are currently required.

## Git Workflow

- Keep related edits local while the website is still being refined.
- Do not create a commit after every small change.
- Run `npm run lint` and `npm run build` when appropriate before proposing a commit.
- Create a commit only when the user explicitly asks, or after agreeing that a meaningful feature or design milestone is complete.
- Before committing, summarize exactly which changes will be included.
- Push to GitHub only when the user explicitly asks, or when the team is ready to update production.
- Once Vercel is connected to the repository, a push to `main` triggers a new production deployment.

## Change Rules for Future Sessions

- Inspect `git status` before editing; preserve unrelated user changes.
- Prefer small, focused edits.
- Put editable profile data in `src/content.js`.
- Use `apply_patch` for source edits.
- Test changed code before committing.
- Do not expose secrets, create fake environment values, or add analytics without explicit approval.
